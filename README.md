# ysSticker

## 概要
画面の最前面に透過ラベルを表示する、シンプルかつ軽量なツールです。<br>
操作中の端末が「本番環境」か「開発環境」かを一目で判別できるようにし、<br>
オペレーションミスを未然に防ぎます。

<img width="250" alt="image" src="https://github.com/user-attachments/assets/6a43d7c0-f844-4fbe-8cb4-e7f4559100c5" />

## 動作環境
- **動作確認済み**：Windows11
- **対応OS(理論上)**：.NetFramework4.8.1が動作するWindows系OS
- **必須コンポーネント**：.NetFramework4.8.1以上

## 特徴
- **最前面表示** : 常に最前面に表示されるため、ウィンドウを切り替えても見失いません。

- **クリック透過**: ラベルの下にあるボタンやウィンドウも、そのまま操作可能です。

- **背景透過**: デスクトップの視認性を損なわず、必要な情報だけを浮かび上がらせます。

- **バージョン表示**：HN由来のseal(アザラシ)型のバージョン表示

## 背景
リモートデスクトップで複数のサーバーを行き来する際、<br>
「今触っているのが本番環境だった」という経験したことはありませんか？<br>
本ツールは、そうした「環境の取り違え」による重大事故を防ぐための、<br>
視覚的な安全装置として開発しました。

## 使用方法
### インストール
　・インストール：
1. ダウンロードした7zファイルを解凍し、中にあるファイル一式を
　　任意のフォルダに配置して実行してください。
1. ステッカー表示内容の変更はタスクトレイアイコンの「設定」から行ってください。
   表示文字、フォント、色の設定が可能です。
   設定は、実行ファイルと同じフォルダのsetting.jsonに保存されます。
1. スタートアップにysSticker.exeのショートカットを置くことで
　　ログイン時に自動的にアプリケーションが起動します。

### アンインストール
1.　配置したファイルをフォルダごと削除してください。
　　レジストリは汚しません。

### 注意事項
- Program Filesなど書き込み制限がある箇所には配置しないでください。
  実行ファイルと同じ階層に設定ファイルを保存するため、書き込み制限により設定保存ができません。
  書き込み権限のあるフォルダに配置してください。
  例）c:\software\ysSticker\　等
